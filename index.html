Automatic presentation flow

Press Start Demo and watch the workflow

The automatic demo plays through the major prototype features like a short guided movie. It uses one temporary example loadout, replaces any previous automated example before starting, and returns here when it is finished.

1
Supervisor access.The demo switches to Supervisor permissions and opens a Technician III loadout.
2
Modify a loadout.It creates a temporary planning loadout, changes headwear and footwear, and moves duty-belt equipment to new clock positions.
3
Save and verify in Team View.The saved configuration is shown on the technician’s mannequin in the Larimer team lineup.
4
Simulate Excel export.The demo opens reporting and shows the technician-loadout export workflow without forcing a file download on the viewer.
