# Prototype Assets

Place approved visual assets for the proof-of-concept in this folder.

Suggested structure:

```text
assets/
├── branding/
│   └── official FRCC logo files
├── mannequin/
│   └── neutral mannequin layers
└── equipment/
    └── equipment icons or transparent PNG/SVG layers
```

Use only approved FRCC branding artwork. Do not recreate, distort, recolor, or modify the official FRCC logo.

For this public prototype, do not add photographs of real Campus Safety employees or files containing sensitive operational information.
